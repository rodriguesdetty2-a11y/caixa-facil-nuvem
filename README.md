# CaixaFácil - Nuvem

Sistema de prestação de contas da GP Liquigás com dados salvos na nuvem (Supabase).

## Stack
- React 18 + Vite
- Supabase (banco de dados na nuvem)
- Hospedagem: Netlify

## Como rodar localmente
```
npm install
npm run dev
```

## Variáveis de ambiente
Copie `.env.example` para `.env.local` e preencha com as credenciais do Supabase.
